# MorphoLex-en data

Morphological segmentations from **MorphoLex-en** (https://github.com/hugomailhot/MorphoLex-en), split into one file per first letter for the Words site. Each line is `word<TAB>segmentation`, where `<x<` is a prefix, `(x)` a root, `>x>` a suffix, `{ }` marks groupings, and `=` means the word is a single root.

Sánchez-Gutiérrez, C. H., Mailhot, H., Deacon, S. H., & Wilson, M. A. (2018). MorphoLex: A derivational morphological database for 70,000 English words. *Behavior Research Methods*, 50, 1568–1580. https://doi.org/10.3758/s13428-017-0981-8
